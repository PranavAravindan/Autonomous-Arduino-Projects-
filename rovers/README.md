# Rovers

Three small rovers, each built to answer a different question.

| Rover | Question it answers | Details |
|---|---|---|
| [Speed rover](speed_rover/) | How fast can a straight run be with gear changes mid-run? | Servo-shifted 3-gear drivetrain |
| [Color rover](color_rover/) | Can a rover choose its behavior from the color of the ground? | TCS34725 color sensor |
| [Terrain rover](terrain_rover/) | Can a rover roam, dodge obstacles, and sample soil moisture? | Ultrasonic sensor, probe arm |
